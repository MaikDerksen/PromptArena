# **App Name**: PromptArena

## Core Features:

- Central Prompt Display: Displays the current central prompt.
- User Prompt Input: Displays two input fields for users to provide image generation prompts
- Image Generation: Generates an image from the user text, using a tool, and displays this in the image panel.
- Live Updates: Live updates of the central prompt, player prompts, and generated images.
- Admin Controls: Admin panel for setting/editing central prompts and controlling the game flow.
- Viewer Display: Displays submitted prompts and the generated images for each player.
- Game State Management: Handles game status transitions: waiting, active, completed.

## Style Guidelines:

- Primary color: Saturated blue (#29ABE2) to convey a sense of technology and creativity.
- Background color: Dark grayish-blue (#2B3035) to support a dark mode aesthetic.
- Accent color: Vivid orange (#FF5733) to highlight key actions and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a techy and modern feel.
- Body font: 'Inter' (sans-serif) for clear readability in longer text sections.
- Responsive layout with stacking on mobile, two-column layout on tablets, and a three-column layout on desktops.
- Smooth transitions and page changes powered by Framer Motion.
